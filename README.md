# Nexocord releases

Downloads for **Nexocord**, your own Discord client mod: 350+ plugins, BetterDiscord plugins and themes, the Nexova theme, Templates & Roles for your servers, and NexBot.

Get the newest version under **[Releases](../../releases/latest)**:

| File | For |
|---|---|
| `Install.Nexocord.exe` | Windows: double-click, **Let's go**, **Install Nexocord** |
| `Nexocord-<version>-linux.run` | Linux: `bash Nexocord-<version>-linux.run` |
| `Nexocord-<version>.apk` | Android (test version) |
| `Nexocord-<version>.ipa` | iPhone and iPad via AltStore or SideStore (test version) |

The installer checks this page for new versions and shows an update button and a notification when one is out.

Help, bug reports and ideas: [Nexocord Discord](https://discord.gg/hSdSmySat8).

Nexocord is free software under the GPL-3.0. The source code ships with every release folder (`source\`).
